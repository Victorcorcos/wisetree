# Color palette

The terminal palette is defined in `src/messages.rs`.

| Purpose | Color |
| --- | --- |
| Brand | `#b47eff` |
| Primary text | `#f8f8f1` |
| Muted text | `#90918a` |
| Secondary text | `#d9d9d2` |
| Errors and deletion | `#ff0071` |
| Success and Merge | `#94e400` |
| Information and Open | `#1cdbf2` |
| Warnings | `#eada61` |
| Activity | `#ff8f00` |
| Background | `#282922` |
| Selected row | `#3e3d31` |
| Focus | `#75705b` |
